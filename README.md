# 鱼缸健康处置台（离线版）

水族店可离线使用的鱼缸健康处置台：维护鱼缸、鱼群与检测记录，按鱼种、缸型与连续检测变化
计算风险，自动生成隔离、换水、复测与用药建议；处置严格经过 **建议 → 执行 → 复测 → 关闭**
四阶段，重复用药与违规跨缸转移一律拦截并说明原因。所有变更进入事件时间线，支持按批次整批
撤销；数据保存在本机浏览器，刷新后自动恢复，损坏数据会被隔离而不是覆盖现有记录。

## 技术栈

React 19 + Vite + TypeScript，零后端、零网络依赖。领域逻辑（`src/domain/`）不依赖
React/localStorage，可直接用 Node 测试。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5105
npm run build    # 类型检查 + 生产构建（含 /sw.js 离线缓存）
npm test         # 37 项 node:test（领域规则 32 + service worker 5）+ 28 项 jsdom 真实挂载冒烟
```

`npm test` 一条命令在 Node 20 与 Node 22+ 均可一次跑通（测试入口显式指定文件而非目录；
jsdom 全局安装器对新版 Node 的只读 `navigator`/`EventTarget` 全局做了重定义与方法绑定）。

首次打开自带演示数据（草缸A / 海缸B / 繁殖缸C + 隔离缸Q，繁殖缸C 有一个进行中工单）。
时间线页可一键「重置为演示数据」。

## 功能与规则

### 风险计算（`src/domain/thresholds.ts`）

区间约定 `[lo, hi)`（含下界、不含上界），边界落在更安全一侧：

| 指标 | 淡水正常 | 关注 | 危急 |
|---|---|---|---|
| pH | `[6.5, 7.5)` | `[6.0,6.5)` 或 `[7.5,8.5)` | `<6.0` 或 `≥8.5` |
| 氨氮 | `[0, 0.02)` ppm | `[0.02, 0.05)` | `≥0.05`（`≥0.2` 标注急性中毒） |
| 亚硝酸盐 | `[0, 0.1)` | `[0.1, 0.25)` | `≥0.25` |
| 硝酸盐 | `[0, 20)` | `[20, 40)` | `≥40` |

- 海缸 pH 上移到 `[8.0, 8.4)`、硝酸盐收紧到 10/20ppm；繁殖缸氨氮/亚硝正常线减半。
- 鱼种偏好叠加：金鱼冷水温、三湖慈鲷偏碱、灯鱼偏酸软水等；同缸多鱼群取最严格结果。
- 连续检测变化：氨氮/亚硝翻倍且超线、pH 单次跳变 ≥0.5、硝酸单次 +20ppm、水温 ±2℃
  都会追加风险；指标分级恶化/改善用于趋势标识。

### 建议生成

氨氮/亚硝危急 → 换水（受单次 **≤50%** 安全上限约束，多条换水建议合并取最大）+ 24h 复测；
危急且有鱼 → 转入隔离缸（店内无隔离缸时给出说明，禁止转入展示缸）；登记鱼病症状
（白点/水霉/烂鳍）→ 对应用药建议；任何非正常评估都带复测动作。

### 四阶段状态机与拦截

`建议 → 执行 → 复测 → 关闭`，只允许相邻流转，跳跃（如建议直接关闭、关闭后再操作）一律
拒绝并给出允许的下一阶段。执行时强制校验：

- **重复用药**：同一缸或同一鱼群（药效随鱼转移），同药 72 小时内拦截，跨工单同样拦截，
  执行清单内部重复也拦截；错误文案含上次用药时间与还需等待的小时数。
- **跨缸转移**：目标缸最近检测危急、源缸危急期转入非隔离缸、鱼群在 72h 用药观察期、
  目标缸不存在或同缸转移，全部拦截并说明原因。
- 换水量必须 `0 < pct ≤ 0.5`；复测必须是建单之后的新检测；关闭必须填写结论。
- 执行动作只能来自建议清单，不能夹带私药。

### 时间线、撤销与数据安全

- 事件溯源：每个用户动作是一个事件批次（缸/鱼群/检测/建单/执行/流转/关闭），UI 状态
  完全由事件重放得到。
- **整批撤销**：撤销按批次进行；若后续批次依赖被撤销实体（如撤缸但缸里后来加过鱼群），
  拒绝并指明悬空依赖，要求先撤后续批次。撤销隔离转移会把鱼带回原缸。
- 持久化：localStorage 保存全部事件。刷新后结构校验 + 严格重放（悬空引用也算损坏）。
- **损坏隔离**：JSON 解析失败、版本未知、事件类型未知、id 重复或悬空引用时，原文连带
  原因隔离保存，主数据以安全空状态启动；可查看原文、丢弃或从备份导入。时间线页提供
  导出/导入 JSON 与「模拟本地数据损坏」演练按钮。
- 防重复提交：领域层按 `clientToken` 幂等（网络重试/双击只产生一个批次），UI 另有提交锁。
